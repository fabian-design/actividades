Actividad: Crear la estructura HTML de una galería de productos

En esta actividad vamos a construir la estructura HTML de una sección de productos para el proyecto Sneaker Shop. El objetivo es organizar correctamente los elementos mediante etiquetas semánticas y contenedores anidados.

Comenzá creando una sección con el identificador products. Dentro de ella agregá una lista desordenada ul con la clase gallery. Cada elemento de la lista (li) debe contener un contenedor div con la clase box.

Dentro de cada contenedor box, incorporá un elemento figure. Este elemento agrupará la imagen del producto (img) y su descripción mediante figcaption.

Dentro de figcaption agregá un título h3 para la descripción o nombre del producto, un párrafo p para mostrar el precio y un elemento time para indicar la fecha.

Consigna: observá la imagen de referencia y escribí el código HTML respetando el orden, la jerarquía y el anidamiento de todas las etiquetas. Utilizá los atributos id, class, src y alt donde corresponda.

Importante: cada etiqueta debe cerrarse correctamente y permanecer dentro del elemento que le corresponde. Recordá que figcaption contiene el título, el precio y la fecha; no reemplaza las etiquetas específicas de cada contenido.
